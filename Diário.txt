# Desenvolvido:

- Criação de um ficheiro `livros.json` com dados iniciais para simular uma base de dados local.

# Problemas: 
- A lista de pesquisa aparecia inicialmente vazia devido ao tempo de resposta assíncrono da leitura do ficheiro JSON.

# Solução: 
- Implementação de um método assíncrono e utilização de `await` na página de pesquisa para obrigar a interface a aguardar o carregamento dos dados.
- Substituição e correção dos URLs das imagens no ficheiro JSON por links funcionais
